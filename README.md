# Weatherglass

参考页面：https://claude.ai/artifact/3bhygX763cPdpcHQYmfrPk

从参考页面公开加载的代码中提取原始 3D 场景、着色器、样式和交互，制作成可独立运行的静态网站。场景脚本与样式保留原文，没有图片替代或 iframe 嵌套，也不需要连接 Claude。原站的账户、分享工具栏属于平台界面，不包含在场景内。

## 运行

安装 Node.js 后，在本目录执行：

```powershell
npm run dev
```

浏览器访问 http://127.0.0.1:4173 。也可以双击 `启动预览.cmd`。

`dist/` 是完整静态网站，可以直接部署到静态托管服务。无需安装依赖或构建。

## 操作

- `1` 手：拖动云朵、按住挤出雨水、晃动产生闪电，拖动太阳改变日照。
- `2` 风：划动吹风。
- `3` 云：在天空按住生成云朵。
- `4` 雾：在山谷涂抹雾气。
- `5` 擦拭：擦去玻璃上的凝结水汽。
- 左下角控制时间和昼夜播放；右下角转盘切换季节。
- 右上角控制声音、全屏和界面显隐；`U` 隐藏或显示界面。

实时动画的位置与画质会受到运行时间、窗口尺寸和显卡性能影响。`reference-integrity.json` 记录原始脚本与样式校验值，可验证内容保持一致。
